# WebSocket Real Endpoint

Get Auth required

Upgrades the connection to a WebSocket scoped to a real-money Options Trading account. Requires a valid one-time password (OTP) from the OTP endpoint, passed as the otp query parameter. Trades placed over this channel settle against the account's real balance.

## Endpoint

Get `/trading/v1/options/ws/real`

Base URL: `https://api.derivws.com`

## Examples

### Request Example

```json
GET /trading/v1/options/ws/real?otp=abc123xyz789

Query Parameters:
  - otp: string (required) — one-time password generated by POST /trading/v1/options/accounts/{accountId}/otp
```

### Response Example

```json
HTTP/1.1 101 Switching Protocols
Upgrade: websocket
Connection: Upgrade

WebSocket connection established successfully.
You can now subscribe to market data and send trading instructions for the real account.
```

## Status Codes

101 Switching Protocols - WebSocket connection established

400 Bad request

401 Unauthorized - Invalid or missing OTP
